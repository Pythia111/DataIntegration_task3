# 作业3 路线1 交付说明（整合版）

本仓库包含 3 个学院端系统（A/B/C）与 1 个集成服务器（Integration Server），均通过 HTTP + XML 交互。

## 1. 模块说明

- projects/A：学院 A（SQL Server + Swing GUI + 登录 + 本地 HTTP 服务 8081）
- projects/B：学院 B（Oracle + Swing GUI + 登录 + 本地 HTTP 服务 8082）
- projects/C：学院 C（MySQL + Swing GUI + 登录 + 本地 HTTP 服务 8083）
- projects/integration：集成服务器（HTTP 服务 8080；课程共享、跨院选课/退选、全局统计）
- projects/ext：扩展/联调代码与补充资源（可构建；不作为必需运行入口）

根目录的 pom.xml 为聚合构建入口，可一次性构建全部模块。

## 2. 构建（Windows / PowerShell）

在根目录执行：

- `mvn -DskipTests clean package`

也可使用脚本：

- `powershell -ExecutionPolicy Bypass -File .\scripts\build-all.ps1`

如需使用指定 Maven，可用完整路径调用 mvn.cmd。

## 3. 启动顺序

建议按以下顺序启动（每个模块在各自目录执行 `mvn exec:java`）：

也可一键启动（会打开 4 个 PowerShell 窗口）：

- `powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1`

1) 启动集成服务器（projects/integration，默认 8080）
- `cd projects/integration`
- `mvn exec:java -Dexec.args=8080`

2) 启动学院 A（projects/A，默认 8081 + GUI）
- `cd projects/A`
- `mvn exec:java`

3) 启动学院 B（projects/B，默认 8082 + GUI）
- `cd projects/B`
- `mvn exec:java`

4) 启动学院 C（projects/C，默认 8083 + GUI）
- `cd projects/C`
- `mvn exec:java`

## 4. 接口一览（用于助教检查）

集成服务器（projects/integration，8080）：
- `GET  /api/integration/sharedCourses?source={A|B|C}` 获取其它学院共享课程（返回为请求学院本地课程 XML）
- `POST /api/integration/courseChoice?source={A|B|C}` 跨院选课/退选（请求体为 choiceReq XML，operation=ENROLL|DROP）
- `GET  /api/integration/statistics` 全局统计（含各院统计 + summary 总计 + timestamp）

学院本地服务（A/B/C，8081/8082/8083）：
- `GET  /api/local/sharedCourses` 返回本院共享课程
- `POST /api/local/enroll` 被集成服务器转发的跨院选课落库
- `POST /api/local/drop` 被集成服务器转发的跨院退选落库
- `GET  /api/local/statistics` 返回本院统计（students/courses/choices）

## 5. 数据库配置（通过 JVM 参数覆盖默认值）

为方便不同机器部署，三个学院端的数据库连接支持使用 JVM 系统参数覆盖：

学院 A：
- `-DcollegeA.db.url=...` `-DcollegeA.db.user=...` `-DcollegeA.db.password=...`

学院 B：
- `-DcollegeB.db.url=...` `-DcollegeB.db.user=...` `-DcollegeB.db.password=...`

学院 C：
- `-DcollegeC.db.url=...` `-DcollegeC.db.user=...` `-DcollegeC.db.password=...`

示例（以学院 C 为例）：
- `mvn exec:java -Dexec.args="" -DcollegeC.db.url="jdbc:mysql://127.0.0.1:3306/CollegeC?..." -DcollegeC.db.user=root -DcollegeC.db.password=123456`

（说明：exec-maven-plugin 对系统参数的透传与终端环境有关，必要时可直接在 IDE 的运行配置里添加 VM options。）

## 6. 作业要求对照（简表）

- A/B/C 均包含 GUI + 登录：见各模块 `gui/LoginFrame` 与 `Main`
- XML + XSD 校验 + XSLT 转换：集成服务器资源位于 projects/integration/src/main/resources/xsd 与 xslt
- 课程共享：集成服务器 `/api/integration/sharedCourses`
- 跨院选课与退选：集成服务器 `/api/integration/courseChoice` + 各学院 `/api/local/enroll|drop`
- 全局统计：集成服务器 `/api/integration/statistics`
