# 可交付性清单（路线1）

对照 [路线1作业要求.md](路线1作业要求.md) 的“需求/要求”，给出可检查点与定位。

## 1) 数据规模（50学生 / 10课程 / 每生5课）

- 学院A（SQL Server）：projects/A/sql/db_init_A.sql（包含 50 学生与选课循环）
- 学院B（Oracle）：projects/B/sql/init_B.sql（注释明确 50/10/250）
- 学院C（MySQL）：projects/C/sql/init.sql（注释明确 50/10/250）

## 2) GUI + 登录

- 学院A/B/C 均提供 Swing GUI 与登录流程（入口为各模块 Main；登录窗体位于各自 gui 包下）。

## 3) 课程共享（集成服务器获取共享课程）

- 集成服务器：projects/integration（端口默认 8080）
- 检查接口：`GET /api/integration/sharedCourses?source={A|B|C}`
- 各学院本地：`GET /api/local/sharedCourses`（8081/8082/8083）

## 4) 跨院选课（导入到课程所属学院数据库）

- 集成服务器：`POST /api/integration/courseChoice?source={A|B|C}`（请求体为 choiceReq XML，operation=ENROLL）
- 各学院落库接口：`POST /api/local/enroll`
- 关键点：集成端会将“统一格式 choice”转换为目标学院本地格式并调用目标学院本地服务。

## 5) 退选流程

- 集成服务器：`POST /api/integration/courseChoice?source={A|B|C}`（operation=DROP）
- 各学院落库接口：`POST /api/local/drop`

## 6) 全局统计（所有学院学生/课程/选课）

- 集成服务器：`GET /api/integration/statistics`
- 返回包含：各学院统计片段 + `<summary>` 总计 + `<timestamp>`
- schema：projects/integration/src/main/resources/xsd/statistics.xsd

## 7) XML / XSD / XSLT

- XSD/XSLT 资源：projects/integration/src/main/resources/xsd 与 xslt
- 运行期校验：集成端与学院端在处理请求/转换时使用 XSD 校验（不通过会返回 error XML 或日志警告）。

## 8) 一键构建/启动（助教检查友好）

- 一键构建：`powershell -ExecutionPolicy Bypass -File .\scripts\build-all.ps1`
- 一键启动：`powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1`
- 运行说明：见 [交付说明.md](交付说明.md)
