# 数据库安装配置指南

你已有 MySQL 在 `D:\mysql\mysql-9.2.0-winx64`（College C ✅ 已就绪）。
还需安装 SQL Server Express（College A）和 Oracle XE（College B）。

---

## 1. SQL Server Express（学院 A）— 约 700MB

### 下载
- 官方链接：https://go.microsoft.com/fwlink/?linkid=2291553
- 选 **Express** 版本（免费），下载安装程序 `SQL2022-SSEI-Expr.exe`

### 安装（关键步骤）
1. 运行安装程序 → 选 **"自定义"** 或 **"基本"**
2. **数据库引擎配置** 页面：
   - 身份验证模式：选 **"混合模式(SQL Server 身份验证和 Windows 身份验证)"**
   - 设置 sa 密码：`YourStrongPassword123`
   - 添加当前用户为 SQL Server 管理员
3. 其余默认即可，安装完成后 **重启**

### 验证安装
```powershell
# 检查服务是否运行
Get-Service MSSQL$SQLEXPRESS
# 或
net start | findstr SQL
```

### 初始化 College A 数据库
```powershell
# 方法1：用 sqlcmd（SQL Server 自带工具）
sqlcmd -S 127.0.0.1\SQLEXPRESS -U sa -P YourStrongPassword123 -i "E:\SE3-2\dataIntegration\DataIntegration_task3\projects\A\sql\db_init_A.sql"

# 方法2：若安装了 SSMS（图形工具），直接在 SSMS 中打开 db_init_A.sql 并执行
```

> 注意：Express 版默认实例名是 `SQLEXPRESS`，代码中 URL 已设为 `jdbc:sqlserver://127.0.0.1:1433`。
> 如果 Express 版监听非 1433 端口，需修改 `projects/A/src/main/java/com/collegeA/util/DatabaseConnection.java` 中的 URL。

### 使 Express 监听 1433 端口（可选，推荐）
1. 打开 **SQL Server 配置管理器**
2. **SQL Server 网络配置** → **SQLEXPRESS 的协议** → 启用 **TCP/IP**
3. 右键 TCP/IP → 属性 → **IP 地址** 选项卡 → 滚动到底部 **IPAll** → TCP 端口设为 `1433`
4. 重启 SQL Server 服务

## 2. Oracle Database XE（学院 B）— 约 2GB

### 下载
- 官方链接：https://www.oracle.com/database/technologies/xe-downloads.html
- 选 **Oracle Database 21c Express Edition for Windows x64**（免费）

### 安装
1. 解压 zip，运行 `setup.exe`，一路下一步
2. 安装时会让你设置 SYS/SYSTEM 密码，记住此密码（如 `Oracle123!`）
3. 安装完成后自动创建：
   - CDB: `XE`（容器数据库）
   - PDB: `XEPDB1`（可插拔数据库，代码连接的就是这个）

### 验证安装
```powershell
# 检查服务
Get-Service OracleServiceXE
Get-Service OracleOraDB21Home1TNSListener

# 测试连接
sqlplus sys/Oracle123!@XEPDB1 as sysdba
```

### 初始化 College B 数据库
```sql
-- 用 sqlplus 连接 XEPDB1
sqlplus sys/Oracle123!@XEPDB1 as sysdba

-- 创建用户（代码中用的 COLLEGEB / CollegeB123）
ALTER SESSION SET CONTAINER=XEPDB1;
CREATE USER COLLEGEB IDENTIFIED BY CollegeB123;
GRANT CONNECT, RESOURCE, DBA TO COLLEGEB;
GRANT UNLIMITED TABLESPACE TO COLLEGEB;

-- 然后用 COLLEGEB 执行初始化脚本
CONNECT COLLEGEB/CollegeB123@XEPDB1
@E:\SE3-2\dataIntegration\DataIntegration_task3\projects\B\sql\init_B.sql
```
