## 4. 集成接口演示

> **推荐**：一键测试脚本
> ```powershell
> powershell -ExecutionPolicy Bypass -File .\scripts\demo-test.ps1
> ```

### 4.1 课程共享

```powershell
Invoke-WebRequest "http://localhost:8080/api/integration/sharedCourses?source=A" -UseBasicParsing | Select-Object -ExpandProperty Content
```

### 4.2 跨院选课（ENROLL）

A 学生 A2026001 选 B 课程 B101：

```powershell
$body = '<choiceReq><traceId>enroll-001</traceId><source>A</source><sid>A2026001</sid><cid>B101</cid><operation>ENROLL</operation></choiceReq>'
Invoke-RestMethod -Method Post -Uri 'http://localhost:8080/api/integration/courseChoice?source=A' -ContentType 'application/xml' -Body $body
```

预期：返回 SUCCESS。

### 4.3 跨院退选（DROP）

```powershell
$body = '<choiceReq><traceId>drop-001</traceId><source>A</source><sid>A2026001</sid><cid>B101</cid><operation>DROP</operation></choiceReq>'
Invoke-RestMethod -Method Post -Uri 'http://localhost:8080/api/integration/courseChoice?source=A' -ContentType 'application/xml' -Body $body
```

预期：返回 SUCCESS。

### 4.4 全局统计

```powershell
Invoke-WebRequest "http://localhost:8080/api/integration/statistics" -UseBasicParsing | Select-Object -ExpandProperty Content
```

预期：150学生/30课程/750选课 + timestamp。
