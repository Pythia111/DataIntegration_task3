## 五、表间关系

### 5.1 关系概览

```text
student (1) ----< sc >---- (1) course
```

### 5.2 关系说明

1. 一个学生可对应多条选课记录。
2. 一门课程可被多个学生选择。
3. `sc` 表通过 `student_id` 与 `course_id` 连接学生表和课程表。

### 5.3 当前校验结果

1. `preprocess.py` 已执行参照完整性检查。
2. 当前清洗结果中，`sc` 表内学号和课程编号均能在对应主表中找到匹配项。

## 六、数据质量说明

### 6.1 当前已确认的缺失值

| 数据集 | 字段 | 缺失数 | 说明 |
|------|------|------:|------|
| students_cleaned.csv | account | 150 | 部分组未提供账号 |

### 6.2 当前已确认的异常值或注意事项

| 数据集 | 字段 | 现象 | 规模 |
|------|------|------|------:|
| 原始 student 数据 | group_no | 存在异常组号 `221250099` 的重复学生记录，清洗后已删除 | 1 条 |
| 原始 course 数据 | share_flag | 存在院系编码 `A` 被写入共享标志，清洗后已归一为 `N` | 10 条 |
| 原始 sc 数据 | course_id | 存在引用不存在课程的选课记录，清洗后已删除 | 1500 条 |
| 全部表 | 编码格式 | 学号、课程号长度和命名规则跨组差异较大 | 普遍存在 |

### 6.3 已执行的预处理规则

1. 删除关键主键字段为空的记录。
2. 去除字符串首尾空格。
3. 将 `gender` 统一为 `M` / `F`。
4. 将 `credit`、`class_hours`、`practice_hours`、`score` 转为数值类型。
5. 将课程表课时缺失填充为 `0`。
6. 将与院系编号相同的 `share_flag` 归一为 `N`。
7. 删除组号异常且存在有效重复项的学生记录。
8. 删除重复选课记录。
9. 删除引用不存在学生或课程的选课记录。
10. 校验 `sc` 表对学生表、课程表的引用完整性。

## 七、使用建议

1. 做组间统计前，优先过滤或单独标记异常 `group_no`。
2. 当前 `share_flag` 已完成归一化，后续共享课程分析可直接按 `Y/N` 使用。
3. 做登录信息相关分析时，需考虑 `account`、`password` 的缺失行。
4. 做成绩分布分析时，应明确区分“未录入成绩”和“成绩为 0”两类情况。
5. 若需要复盘源数据质量问题，应同时参考原始 CSV 与 `data/preprocessing_report.md` 中的清洗说明。

## 八、示例查询

### 8.1 查询 16 组学生数据

```sql
SELECT * FROM student WHERE group_no = 16;
```

### 8.2 统计各组学生数

```sql
SELECT group_no, COUNT(*) AS student_count
FROM student
GROUP BY group_no
ORDER BY student_count DESC;
```

### 8.3 查询共享课程

```sql
SELECT *
FROM course
WHERE share_flag = 'Y';
```

### 8.4 查询成绩缺失的选课记录

```sql
SELECT *
FROM sc
WHERE score IS NULL;
```
